README – Informação Importante

Conta de Administração

O sistema já inclui uma conta de administrador para efeitos de teste:

Username: admin

Password: admin

Esta conta já possui dados pré-carregados, nomeadamente:

Reservas

Check-ins

Estes dados existem exclusivamente para facilitar testes e validação do funcionamento da aplicação.

Dados de Teste (Alojamentos)

Já existem dados de alojamentos (holdings) inseridos no sistema.

Estes dados devem ser utilizados para testes das funcionalidades associadas a reservas e check-ins.

Não é possível adicionar novos alojamentos através do programa.
A criação de alojamentos só pode ser feita manualmente, diretamente nos ficheiros/dados do sistema.

Check-in

O check-in é realizado com base na data atual do sistema.

Objetivo

Todo o conteúdo existente (conta admin e dados pré-carregados) serve apenas para:

Testar funcionalidades

Avaliar o comportamento da aplicação

Facilitar a correção e validação do sistema
